---
title: Search Dark Web Credentials
openapi: "POST /dark-web/credentials/search"
---

Search DarkOwl for leaked credentials matching an email domain, email address, or wallet
address already tracked on one of your organization's brands.

<Warning>
Search results can contain **plaintext leaked passwords** in `password`. The matching row's
password is also left unmasked in `fragment`. Always use HTTPS/TLS, restrict and rotate API
keys, and do not log response bodies or expose them to unauthorized users.
</Warning>

## Authentication and access

Include your API key in the `X-API-KEY` header. Both `slug` and `brandId` are required,
including when you use an organization-scoped key.

The caller must have access to the organization and permission to search its dark web data:

- An organization-scoped API key must match `slug`. A staff user key can name any
  organization.
- A session must belong to a `SUPERUSER`, `SUPPORT`, organization `OWNER`, or organization
  `ADMIN`. Organization members without one of these roles cannot search.
- Dark Web Monitoring must be enabled for the organization.

To find a `brandId`, call [List Organization Brands](/external-api/organization-brands)
using an organization-scoped API key. Use the brand's `id`. See
[List Dark Web Credential Targets](/external-api/dark-web-credentials-targets) to retrieve
the targets available for that brand.

## Request

```bash
curl --request POST \
  --url https://app.chainpatrol.io/api/v2/dark-web/credentials/search \
  --header 'Content-Type: application/json' \
  --header 'X-API-KEY: <api-key>' \
  --data '{
    "slug": "your-org",
    "brandId": 232,
    "kind": "email",
    "target": "security@example.com"
  }'
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `slug` | `string` | Yes | Organization slug. |
| `brandId` | `integer` | Yes | Positive ID of a brand in the organization. |
| `kind` | `"domain" \| "email" \| "crypto"` | Yes | Type of tracked target to search. |
| `target` | `string` | Yes | A target allowlisted for the selected kind and brand. |

The target must already be tracked on the brand. Email targets are trimmed and lowercased;
`0x` wallet targets match case-insensitively. The response's `target` is the normalized
allowlisted value, not the unnormalized input. Pass a raw wallet address, not its CAIP-2
form (for example, do not include `eip155:1:`).

## Response

```json
{
  "kind": "email",
  "target": "security@example.com",
  "resultCount": 12,
  "loadedCount": 12,
  "results": [
    {
      "id": "document-1-0",
      "email": "security@example.com",
      "address": null,
      "source": "Example Leak",
      "leakName": "Example Leak",
      "fragment": "…",
      "crawlDate": "2026-09-30T12:00:00.000Z",
      "password": "plaintext-secret",
      "passwordType": "plaintext"
    }
  ]
}
```

| Field | Type | Description |
| --- | --- | --- |
| `kind` | `string` | Target kind that was searched. |
| `target` | `string` | Normalized allowlisted target. |
| `resultCount` | `number` | Total results reported by DarkOwl. |
| `loadedCount` | `number` | Number of rows in `results`. |
| `results` | `CredentialResult[]` | Leaked credential records returned by DarkOwl. |
| `results[].id` | `string` | `{darkOwlDocumentId}-{index}`; not stable between searches. |
| `results[].email` | `string \| null` | Mailbox for email and domain results; null for crypto. A domain row is null if DarkOwl does not provide an email. |
| `results[].address` | `string \| null` | Wallet address for crypto results; null for email and domain results. |
| `results[].source` | `string` | Leak name, or site when no leak name is available. |
| `results[].leakName` | `string \| null` | Leak name, when available. |
| `results[].fragment` | `string \| null` | Sanitized snippet, up to 1,000 characters. Unrelated emails, phone numbers, payment cards, IP addresses, and street addresses are redacted. The password for this row is not masked. For email and domain searches, this is null if the snippet does not contain the mailbox. Crypto snippets are kept even when they do not repeat the wallet. |
| `results[].crawlDate` | `string` | ISO 8601 timestamp of the crawl. |
| `results[].password` | `string \| null` | Plaintext password returned by DarkOwl, when available. |
| `results[].passwordType` | `string \| null` | Password type reported by DarkOwl, when available. |

There is no caller-supplied page, cursor, or limit. Domain searches page through DarkOwl
results for up to 50 pages and 1,000 rows, so `resultCount` can exceed `loadedCount`. Email
and crypto searches use one DarkOwl page, also capped at 1,000 rows. The response does not
include `passwordPreview`, `revealToken`, `acknowledged`, or `quota`.

Successful searches write a `dark_web.search.executed` audit event with delivery set to
`api`, organization and brand identifiers, kind, normalized target, result counts, API key
ID when available, and the number of passwords returned. Password values are not included
in that event. An audit write failure does not prevent the search response from being
returned. This API has no monthly search quota.

## Errors

| Status | Message / cause |
| --- | --- |
| `400` | Invalid `kind`, `brandId` less than 1, empty `slug` or `target`, or target not tracked on the brand. The target errors are `Domain is not part of this brand's tracked assets`, `Email address is not part of this brand's tracked assets`, or `Wallet address is not part of this brand's tracked assets`. An untracked brand returns the same target error for the requested kind. |
| `401` | `Authentication required. Provide API key or valid session.` |
| `403` | `API key does not have access to organization '…'`; `Only organization owners, admins, or staff can run dark web searches`; or `Dark web monitoring is not enabled for this organization`. |
| `404` | `Organization with slug '…' not found`. |
| `500` | `DarkOwl is currently unavailable. Please try again.` |

Validation failures do not call DarkOwl. Although `gmail.com` is not listed as a domain
target, it can be searched as a domain when the brand has a tracked Gmail address.
