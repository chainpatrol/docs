## Quick Start

### Authentication

Include your API key in the `X-API-KEY` header:

```bash
X-API-KEY: <api-key>
```

## Overview

Search DarkOwl for leaked credentials matching an email domain, email address, or wallet
address already tracked on one of your organization's brands.

<Warning>
Search results can contain **plaintext leaked passwords** in `password`. The matching row's
password is also left unmasked in `fragment`. Always use HTTPS/TLS, restrict and rotate API
keys, and do not log response bodies or expose them to unauthorized users.
</Warning>

## Notes

- Both `slug` and `brandId` are required, including when using an organization-scoped API
  key. `brandId` is the brand's `id` from [List Organization
  Brands](/external-api/organization-brands). See [List Dark Web Credential
  Targets](/external-api/dark-web-credentials-targets) to find tracked search targets.
- Organization-scoped API keys must match `slug`; staff user keys can name any organization.
  Sessions must belong to a `SUPERUSER`, `SUPPORT`, organization `OWNER`, or organization
  `ADMIN`. Dark Web Monitoring must be enabled for the organization.
- The target must already be tracked on the brand. Email targets are trimmed and lowercased;
  `0x` wallet targets match case-insensitively. The returned target is the normalized
  allowlisted value. Pass a raw wallet address, not its CAIP-2 form (for example, omit
  `eip155:1:`). Although `gmail.com` is not listed as a domain target, it can be searched
  when the brand has a tracked Gmail address.
- Domain searches page through DarkOwl results for up to 50 pages and 1,000 rows. Email and
  crypto searches use a single DarkOwl page, also capped at 1,000 rows. The reported total
  (`resultCount`) can exceed the number of rows returned (`loadedCount`). There is no
  caller-supplied page, cursor, or limit.
- Email and domain results contain the mailbox in `email` and have a null `address`; crypto
  results contain the wallet in `address` and have a null `email`. If a domain result has no
  email, both `email` and `fragment` are null.
- Result IDs use `{darkOwlDocumentId}-{index}` and are not stable between searches. `source`
  is the leak name, or the site if there is no leak name; `leakName` is null when unavailable.
  Password and password type are null when DarkOwl does not return them.
- `fragment` is a sanitized snippet up to 1,000 characters. Unrelated emails, phone numbers,
  payment cards, IP addresses, and street addresses are redacted, but the password for the
  result is not masked. For email and domain searches, the fragment is null if it does not
  contain the mailbox. Crypto snippets are retained even when they do not repeat the wallet.
- Successful searches write a `dark_web.search.executed` audit event with delivery set to
  `api`, organization and brand identifiers, kind, normalized target, result counts, API key
  ID when available, and the number of passwords returned (not the passwords). An audit
  write failure does not prevent the search response from being returned. This API has no
  monthly search quota. The response does not include `passwordPreview`, `revealToken`,
  `acknowledged`, or `quota`.
- Invalid `kind`, `brandId` less than 1, empty `slug` or `target`, or a target not tracked
  on the brand returns `400`. Target errors are `Domain is not part of this brand's tracked
  assets`, `Email address is not part of this brand's tracked assets`, or `Wallet address is
  not part of this brand's tracked assets`. A brand outside the organization returns the
  same target error for the requested kind.
- Missing authentication returns `401` (`Authentication required. Provide API key or valid
  session.`). An organization-scoped key for another organization returns `403` (`API key
  does not have access to organization '…'`). An unauthorized session or internal bot key
  returns `403` (`Only organization owners, admins, or staff can run dark web searches`). If
  Dark Web Monitoring is disabled, the response is `403` (`Dark web monitoring is not enabled
  for this organization`). An unknown organization returns `404`
  (`Organization with slug '…' not found`).
- DarkOwl failures return `500` (`DarkOwl is currently unavailable. Please try again.`).
  Validation errors do not call DarkOwl.
