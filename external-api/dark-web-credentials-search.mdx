## Quick Start

### Authentication

Include your API key in the `X-API-KEY` header:

```bash
X-API-KEY: <api-key>
```

## Overview

Search for leaked credentials matching an email domain, email address, or wallet address
tracked on a brand.

<Warning>
Results may contain plaintext passwords. Always use HTTPS, restrict and rotate API keys,
and do not log response bodies or expose them to unauthorized users.
</Warning>

## Notes

- `slug` and `brandId` are required. Find a brand's ID in
  [List Organization Brands](/external-api/organization-brands). The caller must have
  organization access and be an owner, admin, or staff member. Dark Web Monitoring must
  be enabled.
- `kind` must be `domain`, `email`, or `crypto`; `target` must be tracked on the brand.
  Email targets are normalized to lowercase; use a raw wallet address.
- The response includes the normalized target, result counts, and matching credential
  records. Passwords may be null; sensitive values in results must be handled securely.
- Returns `400` for invalid or untracked targets, `401` when unauthenticated, `403`
  without permission or when monitoring is disabled, and `404` when the organization
  cannot be found.
