## Quick Start

### Authentication

Include your API key in the `X-API-KEY` header:

```bash
X-API-KEY: <api-key>
```

## Overview

List the email domains, email addresses, and wallet addresses available for credential
search on a brand.

## Notes

- `slug` and `brandId` are required. Find a brand's ID in
  [List Organization Brands](/external-api/organization-brands).
- Dark Web Monitoring must be enabled. API keys must have access to the requested
  organization; sessions require an organization owner or admin, or staff access.
- Targets come from the brand's tracked email addresses and wallets. Use a raw wallet
  address, not a chain-prefixed value.
- Individual Gmail addresses are listed, but `gmail.com` is not listed as a domain. A
  domain matching the brand website is marked as the default.
- Returns `400` for invalid parameters, `401` when unauthenticated, `403` without
  permission or when monitoring is disabled, and `404` when the organization or brand
  cannot be found.
