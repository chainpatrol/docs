We work with leading wallets and security to block scam links, contract addresses, and
wallet addresses before a user interacts with the scam. ChainPatrol's APIs are offered
as a free service to wallets, security apps, and marketplaces.&#x20;

Every endpoint below lives under `https://app.chainpatrol.io/api/v2` and needs an API
key — see [Authentication](/external-api/authentication). This page indexes the whole
API; the sidebar has the same endpoints grouped the same way.

## Operations and healthchecks

<CardGroup cols={2}>
  <Card
    title="Queues Snapshot"
    icon="layer-group"
    href="/external-api/operations-queues-snapshot"
  >
    Pending review and takedown queue state with SLA and age buckets.
  </Card>

  <Card title="List Healthchecks" icon="stethoscope" href="/external-api/healthchecks-list">
    The registry of healthchecks, including which are implemented.
  </Card>
</CardGroup>

Each healthcheck grades one signal as ok / warn / fail against configurable thresholds:

- [Reviewing Backlog](/external-api/healthchecks-reviewing-backlog) — proposals piling up in review
- [Old Proposals In Review](/external-api/healthchecks-reviewing-old-proposals) — proposals waiting too long
- [Takedowns TODO Volume](/external-api/healthchecks-takedowns-todo-volume) — takedowns not yet filed
- [Takedowns In-Progress Volume](/external-api/healthchecks-takedowns-in-progress-volume) — filed takedowns piling up
- [Stale In-Progress Takedowns](/external-api/healthchecks-takedowns-stale-in-progress) — takedowns stuck past the staleness threshold
- [Cancelled Takedowns Count](/external-api/healthchecks-takedowns-cancelled-count) — excess cancellations over a rolling window
- [Takedown Automation Off](/external-api/healthchecks-takedowns-automation-off) — automation disabled for too long
- [Silent Detection Configs](/external-api/healthchecks-detections-silent-configs) — enabled configs producing no results
- [Dead Asset Spike](/external-api/healthchecks-assets-dead-asset-spike) — spike in recently dead assets
- [Missing Contact URL](/external-api/healthchecks-organization-missing-contact-url) — no main communication channel configured
