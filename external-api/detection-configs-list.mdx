## Overview

List all threat detection sources for an organization. Each source includes its
individual configurations with details such as schedule, status, and source-specific
settings.

To add a new config for a source, use [Create Detection Config](/external-api/detection-configs-create).
To discover the sources you can create configs for, use
[List Detection Sources](/external-api/detection-sources-list).
