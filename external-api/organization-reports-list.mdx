## Overview

Retrieve security reports for your organization. This endpoint returns all reports submitted for your organization, including details about reported assets, proposals, and their current status. The organization is automatically inferred from your API key.

## Quick Start

### Authentication

Include your API key in the `X-API-KEY` header:

```bash
X-API-KEY: your_api_key_here
```

## Query Parameters

| Parameter    | Type    | Required | Description                                                                                           |
| ------------ | ------- | -------- | ----------------------------------------------------------------------------------------------------- |
| limit        | number  | Yes      | Number of reports to return per page (1-20)                                                           |
| cursor       | number  | No       | Cursor for pagination. Pass the `nextCursor` from the previous response to get the next page.         |
| startDate    | string  | No       | Filter reports created after this date (ISO 8601 format)                                              |
| endDate      | string  | No       | Filter reports created before this date (ISO 8601 format)                                             |
| onlyRejected | boolean | No       | If true, only return reports with rejected proposals (default: false)                                 |
| needsCustomerReview | boolean | No | If true, only return reports with at least one proposal waiting on **your** review — the same queue your Review page shows. A proposal qualifies when ChainPatrol escalated it to you and you have not answered yet; approving, rejecting, or escalating it back to ChainPatrol all count as answering. Reports your organization submitted itself are **not** included: ChainPatrol triages those and staff approval blocks the asset without you. Neither is Obligatory Organization Admin Approval enough on its own. Use this to answer "what is waiting on me?", then act on the proposals with [`POST /organization/proposals/{proposalId}/review`](/external-api/organization-proposals-review). |

### Response Fields

| Field                      | Type   | Description                                                              |
| -------------------------- | ------ | ------------------------------------------------------------------------ |
| reports                    | array  | Array of report objects for your organization                            |
| reports[].id               | number | Unique identifier for the report                                         |
| reports[].createdAt        | string | ISO 8601 timestamp when the report was created                           |
| reports[].status           | string | Overall status of the report (`TODO`, `IN_PROGRESS`, `CLOSED`)           |
| reports[].proposals        | array  | Array of proposals associated with the report                            |
| reports[].proposals[].id   | number | Unique identifier for the proposal. Pass it to [`POST /organization/proposals/{proposalId}/review`](/external-api/organization-proposals-review) to approve, reject, or watchlist the proposal. |
| reports[].proposals[].reviewStatus | string | Review state of the proposal (PENDING, APPROVED, REJECTED)        |
| reports[].proposals[].asset | object | The asset the proposal targets. Its `id` is the `assetId` the review endpoint requires. |
| nextCursor                 | number | Cursor for the next page of results (`null` if no more results)          |
| totalCount                 | number | Total number of reports that match your filters                          |

## Pagination

Use the cursor-based pagination to fetch all reports:

<CodeGroup>

```typescript TypeScript
async function fetchAllReports() {
  let allReports = [];
  let cursor: number | null = null;

  while (true) {
    const params = new URLSearchParams({
      limit: "20",
      ...(cursor !== null && { cursor: String(cursor) }),
    });

    const response = await fetch(
      `https://app.chainpatrol.io/api/v2/organization/reports?${params}`,
      {
        method: "GET",
        headers: {
          "X-API-KEY": "YOUR_API_KEY_HERE",
        },
      }
    );

    const data = await response.json();
    allReports = allReports.concat(data.reports);
    cursor = data.nextCursor;

    if (cursor === null) {
      break;
    }
  }

  return allReports;
}

fetchAllReports()
  .then((reports) => console.log(`Total reports: ${reports.length}`))
  .catch((error) => console.error("Error:", error));
```

```python Python
import requests

def fetch_all_reports():
    all_reports = []
    cursor = None

    while True:
        params = {"limit": 20}
        if cursor is not None:
            params["cursor"] = cursor

        response = requests.get(
            "https://app.chainpatrol.io/api/v2/organization/reports",
            headers={"X-API-KEY": "YOUR_API_KEY_HERE"},
            params=params,
        )

        data = response.json()
        all_reports.extend(data["reports"])
        cursor = data.get("nextCursor")

        if cursor is None:
            break

    return all_reports

try:
    reports = fetch_all_reports()
    print(f"Total reports: {len(reports)}")
except Exception as error:
    print(f"Error: {str(error)}")
```

## Filtering Examples

### Filter by Date Range

Get reports from a specific time period:

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/reports?startDate=2024-01-01T00:00:00Z&endDate=2024-03-31T23:59:59Z' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

### Filter Only Rejected Reports

Get reports that have rejected proposals:

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/reports?onlyRejected=true&limit=20' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

### Filter Reports Awaiting Your Review

Get the reports with at least one proposal ChainPatrol escalated to you and you have not answered — the same queue your Review page shows. Reports you submitted yourself are decided by ChainPatrol staff and do not appear here, though they are still returned unfiltered:

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/reports?needsCustomerReview=true&limit=20' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

Each returned report carries the proposals to act on in `proposals[]`. Take `proposals[].id` and `proposals[].asset.id` from there and pass both to [`POST /organization/proposals/{proposalId}/review`](/external-api/organization-proposals-review).

### Combine Filters

Get rejected reports from a specific date range:

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/reports?startDate=2024-01-01T00:00:00Z&endDate=2024-03-31T23:59:59Z&onlyRejected=true&limit=20' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

## Use Cases

### Monitor Recent Reports

```typescript
async function getRecentReports(days: number = 7) {
  const startDate = new Date();
  startDate.setDate(startDate.getDate() - days);

  const response = await fetch(
    `https://app.chainpatrol.io/api/v2/organization/reports?startDate=${startDate.toISOString()}&limit=20`,
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { reports } = await response.json();
  console.log(`Found ${reports.length} reports in the last ${days} days`);
  return reports;
}
```

### Track Rejected Reports

```typescript
async function analyzeRejectedReports() {
  const response = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/reports?onlyRejected=true&limit=20",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { reports } = await response.json();

  // List the assets whose proposals were rejected
  const rejectedAssets = reports.flatMap((report) =>
    report.proposals
      .filter((p) => p.reviewStatus === "REJECTED")
      .map((p) => p.asset.content)
  );

  console.log("Rejected assets:", rejectedAssets);
  return rejectedAssets;
}
```

### Export Reports to CSV

```typescript
async function exportReportsToCSV(startDate: string, endDate: string) {
  const response = await fetch(
    `https://app.chainpatrol.io/api/v2/organization/reports?startDate=${startDate}&endDate=${endDate}&limit=20`,
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { reports } = await response.json();

  const csvHeader = "Report ID,Created At,Status,Proposals\n";
  const csvRows = reports
    .map(
      (r) =>
        `${r.id},${r.createdAt},${r.status},${r.proposals.length}`
    )
    .join("\n");

  const csv = csvHeader + csvRows;

  // Save or return CSV
  return csv;
}
```

## Best Practices

### Pagination
- Use `limit=20` (the maximum) for bulk data retrieval to minimize API calls
- Always check the `nextCursor` field to determine if more results exist
- Store the cursor if you need to resume pagination later

### Date Filtering
- Always use ISO 8601 format for dates: `YYYY-MM-DDTHH:mm:ss.sssZ`
- Include timezone information (typically UTC with `Z` suffix)
- Use both `startDate` and `endDate` for precise time ranges

### Performance
- Cache report data when appropriate to reduce API calls
- Use date filters to limit the result set size
- Consider polling intervals if monitoring for new reports (5-10 minutes recommended)

## Notes

- Organization is automatically determined from your API key
- All timestamps are in ISO 8601 format with UTC timezone
- The `onlyRejected` filter shows reports with at least one rejected proposal, but the report may contain other approved proposals
- Reports are ordered by creation date (newest first)
- Pass `nextCursor` back unchanged as `cursor`
