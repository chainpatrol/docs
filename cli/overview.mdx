The ChainPatrol CLI is a terminal interface to the same platform the dashboard and the
[External API](/external-api/overview) expose. It is built for two audiences at once:
an operator who wants a fast answer without opening the app, and a script or AI agent
that needs machine-readable output and predictable exit codes.

```bash
npm install -g @chainpatrol/cli
chainpatrol login
chainpatrol asset check https://phish.example
```

## Command index

| Command | What it does |
| --- | --- |
| [`login`](/cli/authentication) | Authenticate with ChainPatrol via device-code flow |
| [`logout`](/cli/authentication) | Clear stored credentials from this machine |
| [`whoami`](/cli/authentication) | Show the current authenticated identity |
| [`asset`](/cli/commands/asset) | Check, search, or list assets, or list supported asset types |
| [`reports`](/cli/commands/reports) | Create, list, and search reports |
| [`proposals`](/cli/commands/proposals) | Review proposals waiting on your organization |
| [`detections`](/cli/commands/detections) | Validate, run, list, and update detection configs and results |
| [`configs`](/cli/commands/detections#configs-list) | Shorthand for `detections configs list` |
| [`metrics`](/cli/commands/metrics) | Query organization metrics and breakdowns |
| [`threats`](/cli/commands/threats) | List confirmed threats blocked by ChainPatrol |
| [`takedowns`](/cli/commands/takedowns) | List individual takedown records |
| [`orgs`](/cli/commands/orgs) | List organizations, org assets, and asset groups |
| [`brands`](/cli/commands/orgs#brands-list) | List brands |
| [`healthchecks`](/cli/commands/healthchecks) | List and run organization healthchecks |
| [`queues`](/cli/commands/queues) | Snapshot review and takedown queues |
| [`presets`](/cli/commands/presets) | Run saved workflows for common jobs |
| [`mcp`](/cli/mcp) | Serve the public API to AI agents over MCP (stdio) |
| [`setup`](/cli/agents) | Install the Claude Code skill and shell completions |
| [`uninstall`](/cli/agents) | Remove the Claude Code skill and shell completions |
| [`completions`](/cli/installation#shell-completions) | Output a shell completion script |

## Built-in help

Every command documents itself. `chainpatrol --help` prints the command list, and
`--help` on any command or subcommand prints its full option set:

```bash
chainpatrol --help
chainpatrol reports list --help
chainpatrol help proposals review
```

The help text ships with the binary, so it always matches the version you have installed.
This documentation describes CLI `1.6.x`.
