title: Otras plataformas
sidebarTitle: Otros
description: "Enums de tipos de asset de ChainPatrol para reportar assets de correo electrónico, GitHub, IPFS, OpenSea, DeBank, Google Forms, JotForm, Tawk.to, Teachable y Archive.org."
---

Las etiquetas de abajo coinciden con las de [`POST /threats/list`](/es/external-api/threats-list) y [`POST /detection/list`](/es/external-api/detection-list), excepto `ARCHIVE_ORG`, que está documentado en [`chainpatrol asset types`](/es/cli/commands/asset#asset-types).

| Tipo | Descripción |
| --- | --- |
| `EMAIL` | Direcciones de correo electrónico |
| `GITHUB` | Repositorios/perfiles de GitHub |
| `IPFS` | Hashes de IPFS |
| `OPENSEA` | Colecciones/perfiles de OpenSea |
| `DEBANK` | Perfiles de DeBank |
| `GOOGLE_FORM` | Formularios de Google Forms |
| `JOTFORM` | Formularios de JotForm |
| `TAWK_TO` | Widgets de chat de Tawk.to |
| `TEACHABLE` | Cursos de Teachable |
| `ARCHIVE_ORG` | Instantánea de Wayback de Archive.org |
