---
title: Redes sociales y mensajería
sidebarTitle: Redes sociales
description: "Enums de tipos de asset de ChainPatrol para reportar estafas en Twitter, Telegram, Discord, Facebook, Instagram, TikTok, YouTube y otras plataformas sociales."
---

Las etiquetas de abajo coinciden con las de [`POST /threats/list`](/es/external-api/threats-list) y [`POST /detection/list`](/es/external-api/detection-list). `TWITCH` también aparece en [`POST /organization/assets`](/es/external-api/organization-assets-add).

| Tipo | Descripción |
| --- | --- |
| `TWITTER` | Perfiles/publicaciones de Twitter |
| `TELEGRAM` | Canales/grupos de Telegram |
| `DISCORD_USER` | Usuarios de Discord |
| `DISCORD` | Servidores de Discord (obsoleto) |
| `FACEBOOK` | Perfiles/páginas de Facebook |
| `INSTAGRAM` | Perfiles de Instagram |
| `THREADS` | Perfiles de Threads |
| `TIKTOK` | Perfiles de TikTok |
| `YOUTUBE` | Canales/videos de YouTube |
| `REDDIT` | Publicaciones/subreddits de Reddit |
| `LINKEDIN` | Perfiles de LinkedIn |
| `WHATSAPP` | Contactos de WhatsApp |
| `MEDIUM` | Artículos/perfiles de Medium |
| `FARCASTER` | Perfiles de Farcaster |
| `BLUESKY` | Perfiles de Bluesky |
| `SNAPCHAT` | Perfiles de Snapchat |
| `PINTEREST` | Perfiles/pines de Pinterest |
| `PATREON` | Perfiles de Patreon |
| `SUBSTACK` | Publicaciones de Substack |
| `QUORA` | Perfiles/publicaciones de Quora |
| `PRIMAL` | Perfiles de Primal |
| `DESO` | Perfiles de DeSo |
| `TWITCH` | Identificadores de canales de Twitch |
