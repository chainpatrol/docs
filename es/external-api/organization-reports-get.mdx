## Descripción general

Obtén uno de los reportes de tu organización por su ID, con lo que pasó con cada **Asset** (activo digital: URL, dirección, perfil, app, etc.) que contiene: la revisión de ChainPatrol, si el asset está bloqueado, si seguía online la última vez que se verificó y el **Takedown** (solicitud de baja de contenido fraudulento) de tu organización.

Úsalo para responder "¿qué pasó con este reporte?" o "¿por qué esto sigue activo?" sobre un reporte que ya tienes, por ejemplo a partir del enlace de un reporte en la app de ChainPatrol. El ID es el número que aparece al final del enlace: `app.chainpatrol.io/admin/<slug>/reports/<reportId>`. Si en cambio quieres buscar reportes con filtros, usa [`GET /organization/reports`](/es/external-api/organization-reports-list).

La organización se infiere a partir de tu clave de API. Solo se devuelven los reportes de tu organización: cualquier otro ID devuelve `404`, igual que un ID que no existe.

## Inicio rápido

### Autenticación

Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: your_api_key_here
```

### Solicitud de ejemplo

<CodeGroup>

```typescript TypeScript
const reportId = 1823334;

const response = await fetch(
  `https://app.chainpatrol.io/api/v2/organization/reports/${reportId}`,
  {
    method: "GET",
    headers: {
      "X-API-KEY": "YOUR_API_KEY_HERE",
    },
  }
);

const { report } = await response.json();
console.log(report.assets);
```

```python Python
import requests

report_id = 1823334

response = requests.get(
    f"https://app.chainpatrol.io/api/v2/organization/reports/{report_id}",
    headers={
        "X-API-KEY": "YOUR_API_KEY_HERE",
    },
)

report = response.json()["report"]
print(report["assets"])
```

```bash cURL
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/reports/1823334' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

</CodeGroup>

## Parámetros de ruta

| Parámetro | Tipo   | Obligatorio | Descripción                                                                    |
| --------- | ------ | ----------- | ------------------------------------------------------------------------------ |
| reportId  | number | Sí          | El ID del reporte, tal como aparece en su enlace: `app.chainpatrol.io/admin/<slug>/reports/<reportId>` |

## Parámetros de consulta

| Parámetro | Tipo   | Obligatorio | Descripción                                                                                                                         |
| --------- | ------ | ----------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| slug      | string | No          | Slug de la organización. Omítelo si usas una clave de API de organización, que ya determina la organización. Solo hace falta cuando tus credenciales tienen acceso a más de una organización. |

### Campos de la respuesta

| Campo                                   | Tipo           | Descripción                                                                                                  |
| --------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------ |
| report.id                               | number         | El ID del reporte                                                                                            |
| report.title                            | string         | El título del reporte                                                                                        |
| report.description                      | string         | La descripción del reporte                                                                                   |
| report.status                           | string \| null | El estado del reporte: `TODO`, `IN_PROGRESS` o `CLOSED`                                                      |
| report.reportedByCustomer               | boolean        | Indica si tu organización envió el reporte                                                                   |
| report.slaDueAt                         | string \| null | Fecha límite del SLA para el reporte. `null` cuando no aplica ningún SLA                                     |
| report.duplicateOfId                    | number \| null | ID del reporte del que este es un duplicado. `null` cuando no es un duplicado                                |
| report.createdAt / report.updatedAt     | string         | Marcas de tiempo ISO 8601                                                                                    |
| report.assets                           | array          | Cada asset del reporte, del más antiguo al más reciente                                                      |
| report.assets[].proposalId              | number         | La **Proposal** (propuesta para bloquear o permitir un asset) de este asset en este reporte                  |
| report.assets[].reviewStatus            | string         | La revisión de ChainPatrol de este asset en este reporte: `PENDING`, `APPROVED` o `REJECTED`                 |
| report.assets[].asset.id                | number         | El ID del asset                                                                                              |
| report.assets[].asset.type              | string         | El tipo de asset, por ejemplo `URL`, `TWITTER` o `ADDRESS`                                                   |
| report.assets[].asset.content           | string         | El asset en sí: la URL, el handle o la dirección                                                             |
| report.assets[].asset.status            | string         | El estado actual del asset: `BLOCKED`, `ALLOWED` o `UNKNOWN`                                                 |
| report.assets[].asset.livenessStatus    | string         | Indica si el asset seguía online la última vez que se verificó: `ALIVE`, `DEAD` o `UNKNOWN`                  |
| report.assets[].takedown                | object \| null | El takedown de tu organización para este asset. `null` cuando no se inició ninguno                           |
| report.assets[].takedown.status         | string         | `TODO`, `IN_PROGRESS`, `COMPLETED`, `CANCELLED`, `PENDING_INPUT`, `PENDING_EVIDENCE`, `PENDING_RETRACTION`, `RETRACTION_SENT` o `RETRACTED` |
| report.assets[].takedown.createdAt / updatedAt | string  | Cuándo empezó el takedown y cuándo cambió por última vez                                                     |

## Respuestas de error

### 401 Unauthorized

La clave de API falta o no es válida:

```json
{
  "message": "Authentication required. Provide API key or valid session.",
  "code": "UNAUTHORIZED"
}
```

### 403 Forbidden

Pasaste un `slug` de una organización a la que tus credenciales no tienen acceso.

### 404 Not Found

Ningún reporte con este ID pertenece a tu organización, ya sea porque no existe o porque pertenece a otra organización:

```json
{
  "message": "Report not found",
  "code": "NOT_FOUND"
}
```

## Casos de uso

### ¿Por qué esto sigue activo?

Un asset que está `BLOCKED` ya está en la **Blocklist** (lista de bloqueo) de ChainPatrol, así que las wallets y los navegadores que la usan advierten a las personas. Que esté offline es un paso aparte: el takedown ante el proveedor de hosting o la plataforma del sitio. Lee los dos datos en conjunto:

```typescript
const { report } = await response.json();

for (const { asset, takedown } of report.assets) {
  if (asset.livenessStatus === "ALIVE") {
    console.log(
      `${asset.content} is ${asset.status} and still online; takedown: ${takedown?.status ?? "not started"}`
    );
  }
}
```

## Notas

- El takedown que se muestra es el de tu organización. No se incluye un takedown que otra organización haya presentado sobre el mismo asset.
- `livenessStatus` corresponde a la última verificación, no a una solicitud en tiempo real.
- Todas las marcas de tiempo están en formato ISO 8601 y en UTC.
