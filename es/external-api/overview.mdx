title: External API de ChainPatrol para bloquear URLs y direcciones de estafas
sidebarTitle: Descripción general
description: "Índice de todos los endpoints de la External API de ChainPatrol para quienes integran la Blocklist: verificación de assets, reportes, takedowns, métricas y datos de la organización."
---

Trabajamos con los principales navegadores, antivirus, apps de seguridad, marketplaces y wallets para
bloquear enlaces de estafa, direcciones de contratos y direcciones de wallets antes de que un usuario
interactúe con la estafa. La API también permite a los clientes llevar todos los datos de amenazas de
ChainPatrol —**Suspected Threats** (amenazas sospechosas detectadas automáticamente, todavía sin
confirmar), reportes, **Takedowns** (solicitudes de baja de contenido fraudulento) y cambios en la
**Blocklist** (lista de bloqueo)— directamente a su propio SOC para un monitoreo centralizado.
Las API de ChainPatrol se ofrecen como un servicio gratuito para navegadores, antivirus, apps de
seguridad, marketplaces y wallets.

Todos los endpoints que aparecen a continuación se sirven desde `https://app.chainpatrol.io/api/v2`.
La mayoría necesita una clave de API; consulta [Autenticación de la External API](/es/external-api/authentication) para ver
cómo enviarla. Algunas consultas públicas, como [Verificar asset](/es/external-api/asset-check) y
[Listar assets](/es/external-api/asset-list), también responden sin ella.
Consulta la [Política de obsolescencia de la API](/es/external-api/deprecation-policy) para saber cómo versionamos
la API y cómo te avisamos de los cambios incompatibles (breaking changes).

Los agentes pueden cargar esta documentación desde [llms.txt](https://chainpatrol.com/docs/llms.txt).

## Healthchecks

Los healthchecks (verificaciones de estado) evalúan una sola señal operativa y todos devuelven la
misma estructura de resultado, así que puedes llamarlos en un bucle y procesar las respuestas con
código compartido. Empieza por el registro:

<CardGroup cols={2}>
  <Card title="Listar healthchecks" icon="clipboard-list" href="/es/external-api/healthchecks-list">
    El registro de healthchecks disponibles: llama solo a aquellos en los que `implemented` sea
    true.
  </Card>
</CardGroup>

Las verificaciones individuales:

- [Configuraciones de detección silenciosas](/es/external-api/healthchecks-detections-silent-configs) —
  configuraciones habilitadas que producen muy pocos resultados recientes
- [Backlog de revisión](/es/external-api/healthchecks-reviewing-backlog) — acumulación de
  **Proposals** (propuestas para bloquear o permitir un asset) sin revisar
- [Proposals antiguas en revisión](/es/external-api/healthchecks-reviewing-old-proposals) —
  Proposals que llevan esperando más allá de los umbrales de antigüedad
- [Volumen de Takedowns en TODO](/es/external-api/healthchecks-takedowns-todo-volume) — acumulación de
  takedowns en `TODO`
- [Volumen de Takedowns en IN_PROGRESS](/es/external-api/healthchecks-takedowns-in-progress-volume) —
  acumulación de takedowns en `IN_PROGRESS`
- [Takedowns estancados en IN_PROGRESS](/es/external-api/healthchecks-takedowns-stale-in-progress) —
  takedowns detenidos más allá del umbral de estancamiento
- [Cantidad de Takedowns cancelados](/es/external-api/healthchecks-takedowns-cancelled-count) — exceso
  de cancelaciones en una ventana móvil
- [Takedowns automatizados desactivados](/es/external-api/healthchecks-takedowns-automation-off) —
  automatización apagada durante demasiado tiempo
- [Pico de assets inactivos](/es/external-api/healthchecks-assets-dead-asset-spike) — pico de assets
  detectados como inactivos (`DEAD`)
- [URL de contacto faltante](/es/external-api/healthchecks-organization-missing-contact-url) — no hay
  un canal principal de comunicación configurado

<Note>
  Dos endpoints `POST` están obsoletos y se mantienen solo por compatibilidad con versiones anteriores:
  [`/public/getOrganizationReports`](/es/external-api/organization-reports) —usa
  [`GET /organization/reports`](/es/external-api/organization-reports-list)— y
  [`/public/getOrganizationMetrics`](/es/external-api/organization-metrics) —usa
  [`GET /organization/metrics`](/es/external-api/organization-metrics-list)—.
  [`POST /asset/details`](/es/external-api/asset-details) está marcado como obsoleto en la propia especificación.
</Note>
