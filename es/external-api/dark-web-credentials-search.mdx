## Inicio rápido

### Autenticación

Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: <api-key>
```

## Descripción general

Busca credenciales filtradas que coincidan con un dominio de correo electrónico, una dirección de correo electrónico o una dirección de wallet
que una marca tiene en seguimiento.

<Warning>
Los resultados pueden contener contraseñas en texto plano. Usa siempre HTTPS, restringe y rota las claves de API,
y no registres en logs los cuerpos de las respuestas ni los expongas a usuarios no autorizados.
</Warning>

## Notas

- `slug` y `brandId` son obligatorios. Encuentra el ID de una marca en
  [Listar marcas de la organización](/es/external-api/organization-brands). Quien hace la llamada debe tener
  acceso a la organización y ser propietario, administrador o miembro del staff. Dark Web Monitoring debe
  estar habilitado.
- `kind` debe ser `domain`, `email` o `crypto`; `target` debe estar en seguimiento en la marca.
  Los objetivos de correo electrónico se normalizan a minúsculas; usa una dirección de wallet sin formato.
- La respuesta incluye el objetivo normalizado, los conteos de resultados y los registros de credenciales
  que coinciden. Las contraseñas pueden ser null; los valores sensibles de los resultados deben manejarse de forma segura.
- Devuelve `400` para objetivos no válidos o que no están en seguimiento, `401` cuando no hay autenticación, `403`
  sin permiso o cuando el monitoreo está deshabilitado, y `404` cuando no se encuentra la
  organización.
