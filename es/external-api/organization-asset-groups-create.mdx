## Descripción general

Crea un nuevo grupo de **Assets** (activos digitales: URL, direcciones, perfiles, apps, etc.) para ordenar los assets de tu organización. Los grupos te ayudan a clasificar los assets por tipo, proyecto, propósito o cualquier otro criterio que tenga sentido para tu caso de uso.

## Inicio rápido

### Autenticación

Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: your_api_key_here
```

## Cuerpo de la solicitud

| Campo | Tipo   | Obligatorio | Descripción                                          |
| ----- | ------ | ----------- | ---------------------------------------------------- |
| name  | string | Sí          | Nombre del nuevo grupo (de 1 a 255 caracteres)       |

## Respuesta

### Respuesta exitosa

```json
{
  "id": 4,
  "name": "New Group"
}
```

### Campos de la respuesta

| Campo | Tipo   | Descripción                        |
| ----- | ------ | ---------------------------------- |
| id    | number | Identificador único del grupo      |
| name  | string | Nombre del grupo creado            |

## Respuestas de error

### 400 Bad Request

Se devuelve cuando la solicitud tiene un formato incorrecto o falla la validación:

```json
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "Group name is required"
  }
}
```

```json
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "Group name must be between 1 and 255 characters"
  }
}
```

### 401 Unauthorized

Se devuelve cuando la clave de API falta, no es válida o no tiene acceso a la organización:

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "API key with organization access required"
  }
}
```

### 409 Conflict

Se devuelve cuando ya existe un grupo con el mismo nombre:

```json
{
  "error": {
    "code": "CONFLICT",
    "message": "A group with this name already exists"
  }
}
```

## Buenas prácticas

### Convenciones de nombres

Usa nombres claros y descriptivos que reflejen el propósito del grupo:

```typescript
// Good examples
await createGroup("Official Websites");

// Avoid
await createGroup("Group1"); // Not descriptive
await createGroup("Misc"); // Too vague
await createGroup("test"); // Not professional
```

### Verifica si ya existe el grupo

Antes de crear un grupo, verifica si ya existe uno con el mismo nombre:

```typescript
async function createGroupIfNotExists(groupName: string) {
  // Check if group already exists
  const listResponse = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { groups } = await listResponse.json();
  const existingGroup = groups.find(
    (g) => g.name.toLowerCase() === groupName.toLowerCase()
  );

  if (existingGroup) {
    console.log(`Group "${groupName}" already exists with ID ${existingGroup.id}`);
    return existingGroup;
  }

  // Create new group
  const createResponse = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "X-API-KEY": "YOUR_API_KEY_HERE",
      },
      body: JSON.stringify({ name: groupName }),
    }
  );

  const newGroup = await createResponse.json();
  console.log(`Created new group "${groupName}" with ID ${newGroup.id}`);
  return newGroup;
}
```

### Creación de grupos por lotes

Crea varios grupos en secuencia:

```typescript
async function createMultipleGroups(groupNames: string[]) {
  const results = [];

  for (const name of groupNames) {
    try {
      const response = await fetch(
        "https://app.chainpatrol.io/api/v2/organization/asset-groups",
        {
          method: "POST",
          headers: {
            "Content-Type": "application/json",
            "X-API-KEY": "YOUR_API_KEY_HERE",
          },
          body: JSON.stringify({ name }),
        }
      );

      if (response.ok) {
        const group = await response.json();
        results.push({ name, success: true, id: group.id });
      } else {
        const error = await response.json();
        results.push({ name, success: false, error: error.error.message });
      }
    } catch (error) {
      results.push({ name, success: false, error: String(error) });
    }
  }

  return results;
}

// Usage
const groupNames = ["Websites", "Wallets", "Social Media", "Contracts"];
createMultipleGroups(groupNames).then((results) => {
  const successful = results.filter((r) => r.success).length;
  console.log(`Created ${successful} of ${results.length} groups`);
  
  results.forEach((r) => {
    if (r.success) {
      console.log(`✓ ${r.name} (ID: ${r.id})`);
    } else {
      console.log(`✗ ${r.name}: ${r.error}`);
    }
  });
});
```

Configura una estructura de grupos estándar para una organización nueva:

```typescript

      {

        headers: {
          "Content-Type": "application/json",
          "X-API-KEY": "YOUR_API_KEY_HERE",
        },
        body: JSON.stringify({ name: groupName }),
      }
    );

    if (response.ok) {
      const group = await response.json();

      console.log(`✗ Failed to create "${groupName}"`);
    }
  }

  console.log("Group structure initialization complete");
}
```

async function createProjectGroups(projectName: string) {
  const groupTypes = ["URLs", "Wallets", "Contracts", "Socials"];

          "X-API-KEY": "YOUR_API_KEY_HERE",

    if (response.ok) {
      const group = await response.json();

### Creación dinámica de grupos

Crea grupos de forma dinámica según el tipo de asset:

```typescript
async function ensureGroupForAssetType(assetType: string) {
  const groupName = `${assetType} Assets`;

  // Check if group exists
  const listResponse = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { groups } = await listResponse.json();
  const existingGroup = groups.find((g) => g.name === groupName);

  if (existingGroup) {
    return existingGroup.id;
  }

  // Create new group
  const createResponse = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "X-API-KEY": "YOUR_API_KEY_HERE",
      },
      body: JSON.stringify({ name: groupName }),
    }
  );

  const newGroup = await createResponse.json();
  return newGroup.id;
}

// Usage: Automatically create groups as needed
const urlGroupId = await ensureGroupForAssetType("URL");
const addressGroupId = await ensureGroupForAssetType("ADDRESS");
```

## Mensajes de error comunes

| Mensaje de error                            | Causa                                        | Solución                                |
| ------------------------------------------- | -------------------------------------------- | --------------------------------------- |
| Group name is required                      | Falta el campo `name` en la solicitud        | Incluye un campo `name`                 |
| Group name must be between 1 and 255 characters | El nombre es demasiado corto o demasiado largo | Usa un nombre de 1 a 255 caracteres |
| A group with this name already exists       | Nombre de grupo duplicado                    | Usa un nombre distinto o usa el grupo existente |

## Notas

- Los nombres de los grupos deben ser únicos dentro de tu organización
- Los nombres distinguen entre mayúsculas y minúsculas al verificar que sean únicos
- Los nombres de los grupos tienen una longitud máxima de 255 caracteres
- La organización se determina automáticamente a partir de tu clave de API
- Los grupos recién creados empiezan con cero assets
- Los grupos se pueden renombrar más adelante con el endpoint de actualización
- No hay un límite fijo para la cantidad de grupos por organización
