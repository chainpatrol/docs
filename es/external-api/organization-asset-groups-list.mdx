## Descripción general

Lista todos los grupos de assets (**Asset**: activo digital, como una URL, dirección, perfil, app, etc.) que pertenecen a tu organización. Los grupos de assets te ayudan a organizar tus assets por categoría, proyecto o propósito. Cada grupo incluye un conteo de los assets asignados para facilitar la gestión del inventario.

## Inicio rápido

### Autenticación

Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: your_api_key_here
```

### Campos de la respuesta

| Campo               | Tipo   | Descripción                                                   |
| ------------------- | ------ | ------------------------------------------------------------- |
| groups              | array  | Arreglo de objetos de grupo que pertenecen a tu organización  |
| groups[].id         | number | Identificador único del grupo                                 |
| groups[].name       | string | Nombre visible del grupo                                      |
| groups[].assetCount | number | Cantidad de assets asignados actualmente a este grupo         |

## Respuestas de error

### 401 Unauthorized

Se devuelve cuando falta la clave de API, no es válida o no tiene acceso a la organización:

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "API key with organization access required"
  }
}
```

## Casos de uso

### Mostrar estadísticas de los grupos

```typescript
async function displayGroupStats() {
  const response = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { groups } = await response.json();

  console.log("Asset Group Statistics:");
  console.log("========================");

  groups.forEach((group) => {
    console.log(`${group.name}: ${group.assetCount} assets`);
  });

  const totalAssets = groups.reduce((sum, g) => sum + g.assetCount, 0);
  console.log(`\nTotal: ${totalAssets} assets across ${groups.length} groups`);
}
```

### Buscar un grupo por nombre

```typescript
async function findGroupByName(groupName: string) {
  const response = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { groups } = await response.json();
  const group = groups.find((g) => g.name.toLowerCase() === groupName.toLowerCase());

  if (group) {
    console.log(`Found group "${group.name}" (ID: ${group.id}) with ${group.assetCount} assets`);
    return group;
  } else {
    console.log(`Group "${groupName}" not found`);
    return null;
  }
}

// Usage
findGroupByName("Wallets");
```

### Identificar grupos vacíos

```typescript
async function findEmptyGroups() {
  const response = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );

  const { groups } = await response.json();
  const emptyGroups = groups.filter((g) => g.assetCount === 0);

  if (emptyGroups.length > 0) {
    console.log(`Found ${emptyGroups.length} empty groups:`);
    emptyGroups.forEach((g) => console.log(`  - ${g.name} (ID: ${g.id})`));
  } else {
    console.log("No empty groups found");
  }

  return emptyGroups;
}
```

### Monitorear el crecimiento de los grupos

```typescript
async function monitorGroupGrowth() {
  const response = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/asset-groups",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }

  const sortedGroups = [...groups].sort((a, b) => b.assetCount - a.assetCount);

  sortedGroups.forEach((group, index) => {
    const percentage = groups.reduce((sum, g) => sum + g.assetCount, 0);
    const groupPercentage = ((group.assetCount / percentage) * 100).toFixed(1);
    console.log(
      `${index + 1}. ${group.name}: ${group.assetCount} assets (${groupPercentage}%)`
    );
  });
}
```

## Buenas prácticas

### Caché

- Guarda en caché las listas de grupos cuando construyas menús desplegables en la interfaz para reducir las llamadas a la API
- Invalida la caché cuando se creen, actualicen o eliminen grupos
- Considera un TTL de caché de 5 a 10 minutos para los casos de uso típicos

### Rendimiento

- Este endpoint devuelve todos los grupos en una sola solicitud (no se necesita paginación)
- Los grupos suelen ser pocos (< 100 en la mayoría de las organizaciones)
- Usa este endpoint para construir tablas de búsqueda que relacionen el ID de cada grupo con su nombre

### Integración

```typescript
// Create a helper class for group management
class GroupManager {
  private apiKey: string;
  private cache: Map<number, { name: string; assetCount: number }> = new Map();
  private cacheTime: number = 0;
  private cacheTTL: number = 5 * 60 * 1000; // 5 minutes

  constructor(apiKey: string) {
    this.apiKey = apiKey;
  }

  async getGroups(forceRefresh: boolean = false) {
    if (!forceRefresh && Date.now() - this.cacheTime < this.cacheTTL) {
      return Array.from(this.cache.values());
    }

    const response = await fetch(
      "https://app.chainpatrol.io/api/v2/organization/asset-groups",
      {
        headers: { "X-API-KEY": this.apiKey },
      }
    );

    const { groups } = await response.json();
    
    this.cache.clear();
    groups.forEach((g) => {
      this.cache.set(g.id, { name: g.name, assetCount: g.assetCount });
    });
    this.cacheTime = Date.now();

    return groups;
  }

  async getGroupName(groupId: number): Promise<string | null> {
    if (this.cache.has(groupId)) {
      return this.cache.get(groupId)!.name;
    }

    await this.getGroups();
    return this.cache.get(groupId)?.name || null;
  }

  invalidateCache() {
    this.cache.clear();
    this.cacheTime = 0;
  }
}

// Usage
const manager = new GroupManager("YOUR_API_KEY_HERE");
const groups = await manager.getGroups();
const groupName = await manager.getGroupName(1);
```

## Notas

- La organización se determina automáticamente a partir de tu clave de API
- Todos los grupos que pertenecen a tu organización se devuelven en una sola respuesta
- `assetCount` refleja la cantidad actual de assets asignados a cada grupo
- Los grupos con cero assets igualmente se incluyen en la respuesta
- Los ID de grupo son únicos dentro de tu organización
- Este endpoint no admite paginación porque la cantidad de grupos suele ser pequeña
