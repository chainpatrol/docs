## Inicio rápido

### Autenticación

Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: <api-key>
```

## Descripción general

Lista los dominios de correo electrónico, las direcciones de correo electrónico y las direcciones de wallet disponibles para la
búsqueda de credenciales en una marca.

## Notas

- `slug` y `brandId` son obligatorios. Encuentra el ID de una marca en
  [Listar marcas de la organización](/es/external-api/organization-brands).
- Dark Web Monitoring debe estar habilitado. Las claves de API deben tener acceso a la
  organización solicitada; las sesiones requieren un propietario o administrador de la organización, o acceso de staff.
- Los objetivos provienen de las direcciones de correo electrónico y las wallets que la marca tiene en seguimiento. Usa una dirección
  de wallet sin formato, no un valor con prefijo de cadena.
- Las direcciones individuales de Gmail se listan, pero `gmail.com` no se lista como dominio. Un
  dominio que coincide con el sitio web de la marca se marca como el predeterminado.
- Devuelve `400` para parámetros no válidos, `401` cuando no hay autenticación, `403` sin
  permiso o cuando el monitoreo está deshabilitado, y `404` cuando no se encuentra la organización o la
  marca.
