## Descripción general

Lista todas las configuraciones de detección de amenazas de una organización, agrupadas por fuente. Cada fuente incluye sus
configuraciones individuales con detalles como la programación, el estado y los ajustes
específicos de la fuente.

Para agregar una configuración nueva a una fuente, usa [Crear configuración de detección](/es/external-api/detection-configs-create).
Para descubrir las fuentes para las que puedes crear configuraciones, usa
[Listar fuentes de detección](/es/external-api/detection-sources-list).
