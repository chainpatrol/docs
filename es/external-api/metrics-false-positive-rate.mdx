---
title: Obtener tasa de falsos positivos
openapi: "POST /metrics/false-positive-rate"
---

## Descripción general

Obtén la proporción de bloqueos que luego se revirtieron, para los **assets** (activos digitales: URL, dirección, perfil, app, etc.) bloqueados en un rango de fechas.
Un bloqueo cuenta como falso positivo cuando el asset ya no está bloqueado hoy.

```bash
curl --request POST \
  --url https://app.chainpatrol.io/api/v2/metrics/false-positive-rate \
  --header 'Content-Type: application/json' \
  --header 'X-API-KEY: <api-key>' \
  --data '{
    "startDate": "2026-08-01",
    "endDate": "2026-09-30"
  }'
```

## Cuerpo de la solicitud

| Campo          | Tipo       | Obligatorio | Descripción                                                                                                                              |
| -------------- | ---------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `slug`         | `string`   | ❌ No       | Slug de la organización. Opcional con una clave de API de organización, que usa su propia organización. No lo envíes junto con `slugs`.  |
| `slugs`        | `string[]` | ❌ No       | Varias organizaciones a la vez, hasta 200. Cada una se verifica con tus credenciales, y si no tienes acceso a alguna, la llamada falla.  |
| `startDate`    | `string`   | ❌ No       | Solo assets bloqueados en esta fecha o después. Un valor de solo fecha (`YYYY-MM-DD`) empieza a la medianoche UTC.                       |
| `endDate`      | `string`   | ❌ No       | Solo assets bloqueados en esta fecha o antes. Un valor de solo fecha abarca todo el día en UTC.                                          |
| `brandIds`     | `number[]` | ❌ No       | Solo assets que pertenecen a estas marcas.                                                                                               |
| `countryCodes` | `string[]` | ❌ No       | Solo assets escaneados desde estos países (códigos ISO 3166-1 alpha-2).                                                                  |

## Cómo leer la respuesta

Cada desglose incluye `blocked`, `falsePositives` y `falsePositiveRate`
(`falsePositives / blocked`, de 0 a 1, o `null` cuando no se bloqueó nada).

- `total` agrupa todas las organizaciones solicitadas: todos los falsos positivos sobre todos los bloqueos,
  no un promedio de las tasas por organización.
- `byOrganization` tiene una entrada por cada organización solicitada, ordenadas de mayor a menor cantidad de bloqueos. Una
  organización que no bloqueó nada en el rango aparece con `blocked: 0`.
- `byAssetType` lista todos los tipos de asset bloqueados en el rango, incluidos los tipos sin
  falsos positivos.

<Warning>
  Si un bloqueo sigue vigente se evalúa tal como está en este momento. Un rango reciente da un valor bajo porque
  sus reversiones todavía no ocurrieron, así que compara rangos que hayan tenido el mismo tiempo
  para estabilizarse.
</Warning>
