## Descripción general

Lista todos los **Assets** (activos digitales: URL, direcciones, perfiles, apps, etc.) que
sigues en una organización, del más reciente al más antiguo, con el estado actual de cada
asset y el **Takedown** (solicitud de baja de contenido fraudulento) de tu organización para
ese asset.

Úsalo para ver los cambios de estado sin esperar el correo: consúltalo periódicamente y
compara `status` y `takedown.status` con lo que viste la última vez. Cada persona puede
seguir como máximo 100 assets por organización, así que la lista nunca se pagina.

Requiere una clave de API de usuario (user-scoped) o una sesión iniciada,
y muestra solo **tus** seguimientos, no los de otras personas de tu organización.

## Inicio rápido

### Autenticación

Incluye tu clave de API de usuario en el encabezado `X-API-KEY`:

```bash
X-API-KEY: <api-key>
```

## Parámetros de consulta

| Parámetro | Tipo     | Obligatorio | Descripción                                                                                                 |
| --------- | -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `slug`    | `string` | No          | Slug de la organización. Obligatorio solo cuando tus credenciales tienen acceso a más de una organización.  |

## Respuesta

```json
{
  "follows": [
    {
      "assetId": 4175269,
      "content": "your-brand-login.example",
      "type": "URL",
      "status": "BLOCKED",
      "deleted": false,
      "followedAt": "2026-10-06T22:34:47.912Z",
      "takedown": { "id": 8812, "status": "IN_PROGRESS" }
    }
  ],
  "followCount": 1,
  "limit": 100,
  "warnThreshold": 90,
  "canFollowMore": true,
  "warning": null
}
```

| Campo                       | Tipo             | Descripción                                                                                              |
| --------------------------- | ---------------- | -------------------------------------------------------------------------------------------------------- |
| `follows[].assetId`         | `number`         | ID del asset.                                                                                            |
| `follows[].content`         | `string`         | Contenido del asset (URL, nombre de usuario, dirección, …).                                              |
| `follows[].type`            | `string`         | Tipo de asset.                                                                                           |
| `follows[].status`          | `string`         | Estado actual del asset: `UNKNOWN`, `ALLOWED` o `BLOCKED`.                                               |
| `follows[].deleted`         | `boolean`        | El asset fue eliminado. Ya no envía correos, pero sigue contando para `limit` hasta que dejes de seguirlo. |
| `follows[].followedAt`      | `string`         | Cuándo empezaste a seguir el asset.                                                                      |
| `follows[].takedown`        | `object \| null` | El takedown de tu organización para el asset (su `id` y `status`), o `null` si no hay ninguno.           |
| `followCount`               | `number`         | Cuántos assets sigues en esta organización.                                                              |
| `limit`, `warnThreshold`, `canFollowMore`, `warning` | `number`, `number`, `boolean`, `string \| null` | Tu límite de seguimientos, igual que en [Seguir asset](/es/external-api/asset-follow#respuesta).   |
