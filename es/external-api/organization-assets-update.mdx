## Descripción general

Actualiza el nombre, la descripción o la asignación de grupo de un **Asset** (activo digital: URL, dirección, perfil, app, etc.). Este endpoint te permite modificar los metadatos de los assets que pertenecen a tu organización. El contenido y el tipo del asset no se pueden cambiar: crea un asset nuevo si necesitas modificar esos campos.

## Inicio rápido

### Autenticación

Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: your_api_key_here
```

## Parámetros de ruta

| Parámetro | Tipo   | Obligatorio | Descripción                          |
| --------- | ------ | ----------- | ------------------------------------ |
| assetId   | number | Sí          | ID del asset que se va a actualizar  |

## Cuerpo de la solicitud

| Campo       | Tipo            | Obligatorio | Descripción                                                                                           |
| ----------- | --------------- | ----------- | ----------------------------------------------------------------------------------------------------- |
| assetId     | number          | Sí          | ID del asset que se va a actualizar (debe coincidir con el parámetro de ruta)                         |
| name        | string          | No          | Nuevo nombre visible del asset. Omítelo para dejarlo sin cambios.                                     |
| description | string \| null  | No          | Nueva descripción del asset. Pasa `null` para borrarla. Omítela para dejarla sin cambios.             |
| groupId     | number \| null  | No          | Nuevo ID de grupo para asignar. Pasa `null` para quitarlo del grupo. Omítelo para dejarlo sin cambios. |

<Note>
  Para actualizar el asset se debe proporcionar al menos uno de estos campos: `name`, `description` o `groupId`.
</Note>

## Respuesta

### Respuesta exitosa

```json
{
  "id": 12345,
  "content": "https://example.com",
  "name": "Updated Name",
  "description": "Updated description",
  "groupId": 2
}
```

### Campos de la respuesta

| Campo       | Tipo          | Descripción                                             |
| ----------- | ------------- | ------------------------------------------------------- |
| id          | number        | ID del asset                                            |
| content     | string        | Contenido del asset (sin cambios)                       |
| name        | string        | Nombre visible actualizado                              |
| description | string \| null | Descripción actualizada (null si se borró)             |
| groupId     | number \| null | ID de grupo actualizado (null si no tiene grupo)       |

## Respuestas de error

### 400 Bad Request

Se devuelve cuando la solicitud está mal formada o contiene datos no válidos:

```json
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "At least one field (name, description, or groupId) must be provided"
  }
}
```

### 401 Unauthorized

Se devuelve cuando falta la clave de API, no es válida o no tiene acceso a la organización:

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "API key with organization access required"
  }
}
```

### 403 Forbidden

Se devuelve cuando el asset no pertenece a tu organización:

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "Asset does not belong to your organization"
  }
}
```

### 404 Not Found

Se devuelve cuando el ID del asset o el ID del grupo no existe:

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Asset with ID 12345 not found"
  }
}
```

## Mensajes de error comunes

| Mensaje de error                               | Causa                                                      | Solución                                              |
| ---------------------------------------------- | ---------------------------------------------------------- | ----------------------------------------------------- |
| Asset with ID {id} not found                   | ID de asset no válido                                      | Verifica que el ID del asset exista                   |
| Asset does not belong to your organization     | El asset pertenece a otra organización                     | Usa un ID de asset de tu organización                 |
| Group with ID {id} not found                   | ID de grupo no válido                                      | Usa un ID de grupo válido de tu organización          |
| At least one field must be provided            | Solicitud de actualización vacía                           | Proporciona al menos un campo para actualizar         |
| Path parameter assetId does not match body     | Los ID de asset de la URL y del cuerpo no coinciden        | Asegúrate de que ambos ID de asset coincidan          |

## Buenas prácticas

### Actualización de campos

- **Actualizaciones parciales**: incluye solo los campos que quieras cambiar
- **Null frente a omitir**: 
  - Pasa `null` para borrar un campo (description, groupId)
  - Omite el campo para dejarlo sin cambios
- **Validación**: valida que los ID de grupo existan antes de actualizar

### Actualizaciones masivas

Cuando actualices varios assets, procésalos de forma secuencial o en lotes pequeños:

```typescript
async function updateMultipleAssets(updates: Array<{ id: number; data: any }>) {
  const results = [];

  for (const update of updates) {
    try {
      const response = await fetch(
        `https://app.chainpatrol.io/api/v2/organization/assets/${update.id}`,
        {
          method: "PATCH",
          headers: {
            "Content-Type": "application/json",
            "X-API-KEY": "YOUR_API_KEY_HERE",
          },
          body: JSON.stringify({
            assetId: update.id,
            ...update.data,
          }),
        }
      );

      const data = await response.json();
      results.push({ id: update.id, success: true, data });
    } catch (error) {
      results.push({ id: update.id, success: false, error });
    }
  }

  return results;
}

// Update multiple assets
const updates = [
  { id: 12345, data: { name: "Updated Name 1" } },
  { id: 12346, data: { groupId: 2 } },
  { id: 12347, data: { description: null } },
];

updateMultipleAssets(updates)
  .then((results) => console.log("Update results:", results));
```

### Manejo de errores

- Verifica la propiedad del asset antes de actualizarlo (comprueba si el asset pertenece a tu organización)
- Valida los ID de grupo antes de asignarlos
- Maneja los errores 404 de forma controlada (es posible que el asset se haya eliminado)
- Registra las actualizaciones fallidas con fines de auditoría

## Casos de uso

### Organizar assets en grupos

```typescript
// Move all URL assets to "Websites" group
async function organizeURLAssets() {
  // First, get all URL assets
  const listResponse = await fetch(
    "https://app.chainpatrol.io/api/v2/organization/assets?type=URL",
    {
      headers: { "X-API-KEY": "YOUR_API_KEY_HERE" },
    }
  );
  const { assets } = await listResponse.json();

  // Then update each to assign to group
  for (const asset of assets) {
    await fetch(
      `https://app.chainpatrol.io/api/v2/organization/assets/${asset.id}`,
      {
        method: "PATCH",
        headers: {
          "Content-Type": "application/json",
          "X-API-KEY": "YOUR_API_KEY_HERE",
        },
        body: JSON.stringify({
          assetId: asset.id,
          groupId: 1, // Websites group
        }),
      }
    );
  }
}
```

### Agregar descripciones a los assets

```typescript
// Add descriptions to assets that don't have them
async function addDescriptions(assetDescriptions: Map<number, string>) {
  for (const [assetId, description] of assetDescriptions) {
    await fetch(
      `https://app.chainpatrol.io/api/v2/organization/assets/${assetId}`,
      {
        method: "PATCH",
        headers: {
          "Content-Type": "application/json",
          "X-API-KEY": "YOUR_API_KEY_HERE",
        },
        body: JSON.stringify({
          assetId,
          description,
        }),
      }
    );
  }
}
```

## Notas

- El contenido y el tipo del asset no se pueden modificar: crea un asset nuevo si lo necesitas
- Solo se pueden actualizar los assets que pertenecen a tu organización
- La organización se determina automáticamente a partir de tu clave de API
- Todas las operaciones de actualización son atómicas: o se actualizan todos los campos o no se actualiza ninguno
- La respuesta contiene la información actualizada del asset
- La marca de tiempo `updatedAt` del asset se actualizará cuando cambie cualquier campo
