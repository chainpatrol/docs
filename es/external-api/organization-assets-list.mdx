## Descripción general

Lista todos los assets (**Asset**: activo digital, como una URL, dirección, perfil, app, etc.) que pertenecen a tu organización, con filtros opcionales por tipo, grupo y consulta de búsqueda. La organización se infiere automáticamente a partir de tu clave de API. Este endpoint admite paginación para manejar de forma eficiente colecciones grandes de assets.

## Inicio rápido

### Autenticación

Todos los endpoints de organización requieren una clave de API con acceso a la organización. Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: your_api_key_here
```

## Parámetros de consulta

| Parámetro | Tipo   | Obligatorio | Descripción                                                                                                                                                                                                      |
| --------- | ------ | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| type      | string | No          | Filtra por tipo de asset: `URL`, `ADDRESS`, `PAGE`, `DISCORD`, `TELEGRAM`, `TWITTER`, `INSTAGRAM`, `MEDIUM`, `GITHUB`, `YOUTUBE`, `LINKEDIN`, `TWITCH`, `TIKTOK`, `EMAIL`                                         |
| groupId   | number | No          | Filtra por ID de grupo. Usa `-1` para obtener solo los assets sin grupo. Omítelo para incluir todos los assets, sin importar a qué grupo estén asignados.                                                        |
| query     | string | No          | Consulta de búsqueda para filtrar assets por contenido. Realiza una búsqueda que no distingue entre mayúsculas y minúsculas en los campos de contenido, nombre y descripción del asset.                          |
| per_page  | number | No          | Cantidad de assets que se devuelven por página. Rango válido: 1-1000. Valor predeterminado: 100. Usa valores más grandes para operaciones masivas y valores más pequeños para una paginación ágil en la interfaz. |
| next_page | string | No          | Token de cursor para obtener la siguiente página de resultados. Este valor se devuelve en la respuesta cuando hay más resultados disponibles. Pásalo en las solicitudes siguientes para continuar la paginación.  |

### Campos de la respuesta

| Campo                | Tipo   | Descripción                                                                                                  |
| -------------------- | ------ | ------------------------------------------------------------------------------------------------------------ |
| assets               | array  | Arreglo de objetos de asset que pertenecen a tu organización                                                 |
| assets[].id          | number | Identificador único del asset                                                                                |
| assets[].content     | string | El contenido real del asset (URL, dirección, handle, etc.)                                                   |
| assets[].type        | string | Clasificación del tipo de asset                                                                              |
| assets[].status      | string | Estado del asset, normalmente `ALLOWED` para los assets de la organización                                   |
| assets[].name        | string | Nombre visible del asset (opcional)                                                                          |
| assets[].description | string | Descripción del asset (opcional, puede ser null)                                                             |
| assets[].group       | object | Objeto de grupo que contiene `id` y `name` si el asset está asignado a un grupo; null si no tiene grupo      |
| assets[].createdAt   | string | Marca de tiempo ISO 8601 del momento en que se creó el asset                                                 |
| assets[].updatedAt   | string | Marca de tiempo ISO 8601 del momento en que se actualizó el asset por última vez                             |
| assets[].allowlistExpiresAt | string | Marca de tiempo ISO 8601 del momento en que vence la entrada del asset en la **Allowlist** (lista de permitidos). `null` cuando nunca vence. Consulta [Definir vencimiento de assets de la organización](/es/external-api/organization-assets-expiry) |
| assets[].allowlistExpiredAt | string | Marca de tiempo ISO 8601 del momento en que pasó el vencimiento y comenzó el período de gracia de 14 días. `null` hasta entonces |
| next_page            | string | Token de cursor para la siguiente página de resultados. Undefined/null cuando no hay más resultados disponibles. |

## Paginación

Para obtener todos los assets, usa el cursor `next_page` que se devuelve en cada respuesta:

<CodeGroup>

```typescript TypeScript
async function fetchAllAssets() {
  let allAssets = [];
  let nextPage: string | undefined = undefined;

  while (true) {
    const params = new URLSearchParams({
      per_page: "500",
      ...(nextPage && { next_page: nextPage }),
    });

    const response = await fetch(
      `https://app.chainpatrol.io/api/v2/organization/assets?${params}`,
      {
        method: "GET",
        headers: {
          "X-API-KEY": "YOUR_API_KEY_HERE",
        },
      }
    );

    const data = await response.json();
    allAssets = allAssets.concat(data.assets);
    nextPage = data.next_page;

    if (!nextPage) {
      break;
    }
  }

  return allAssets;
}

fetchAllAssets()
  .then((assets) => console.log(`Total assets: ${assets.length}`))
  .catch((error) => console.error("Error:", error));
```

```python Python
import requests

def fetch_all_assets():
    all_assets = []
    next_page = None

    while True:
        params = {"per_page": 500}
        if next_page:
            params["next_page"] = next_page

        response = requests.get(
            "https://app.chainpatrol.io/api/v2/organization/assets",
            headers={"X-API-KEY": "YOUR_API_KEY_HERE"},
            params=params,
        )

        data = response.json()
        all_assets.extend(data["assets"])
        next_page = data.get("next_page")

        if not next_page:
            break

    return all_assets

try:
    assets = fetch_all_assets()
    print(f"Total assets: {len(assets)}")
except Exception as error:
    print(f"Error: {str(error)}")
```

## Ejemplos de filtrado

### Filtrar por tipo

Obtén solo los assets de tipo URL:

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/assets?type=URL' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

### Filtrar por grupo

Obtén los assets de un grupo específico:

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/assets?groupId=1' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

Obtén solo los assets sin grupo:

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/assets?groupId=-1' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

### Buscar assets

Busca assets que contengan "wallet":

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/assets?query=wallet' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

### Combinar filtros

Obtén los assets de tipo URL del grupo 1 que contengan "main":

```bash
curl -X GET 'https://app.chainpatrol.io/api/v2/organization/assets?type=URL&groupId=1&query=main' \
  -H 'X-API-KEY: YOUR_API_KEY_HERE'
```

## Respuestas de error

### 401 Unauthorized

Se devuelve cuando falta la clave de API, no es válida o no tiene acceso a la organización:

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "API key with organization access required"
  }
}
```

### 400 Bad Request

Se devuelve cuando los parámetros de consulta no son válidos:

```json
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "Invalid asset type provided"
  }
}
```

## Buenas prácticas

### Paginación

- Usa `per_page=500` o más para operaciones masivas, a fin de minimizar las llamadas a la API
- Usa `per_page=50-100` para la paginación en la interfaz, a fin de ofrecer una experiencia de usuario ágil
- Revisa siempre si la respuesta incluye `next_page` para determinar si hay más resultados

### Filtrado

- Aplica los filtros del lado del servidor en lugar de obtener todos los assets y filtrarlos del lado del cliente
- Combina filtros para acotar los resultados de forma eficiente
- Usa el parámetro `query` para funciones de búsqueda impulsadas por el usuario

### Rendimiento

- Guarda en caché las listas de assets cuando corresponda para reducir las llamadas a la API
- Usa valores de `per_page` adecuados según tu caso de uso
- Considera implementar una carga incremental para conjuntos de datos grandes

## Notas

- La organización se determina automáticamente a partir de tu clave de API
- Todas las marcas de tiempo están en formato ISO 8601 con zona horaria UTC
- El `status` de los assets de la organización normalmente es `ALLOWED`
- El campo `group` es `null` cuando un asset no está asignado a ningún grupo
- El cursor `next_page` es opaco y no se debe analizar ni modificar
