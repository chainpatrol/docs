## Descripción general

Busca reportes existentes dentro de tu organización según el contenido del **Asset** (activo
digital: URL, dirección, perfil, app, etc.). Úsalo para comprobar si ya existe un reporte antes
de crear uno nuevo con [Crear reporte](/es/external-api/report-create).
