## Descripción general

Cuenta los **Takedowns** (solicitudes de baja de contenido fraudulento) que están en
estado `TODO` para la organización. Una acumulación suele indicar una brecha de
automatización en una nueva superficie de amenaza o problemas de capacidad del equipo de
takedowns para presentar solicitudes manualmente.
