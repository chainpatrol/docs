## Inicio rápido

### Autenticación

Incluye tu clave de API en el encabezado `X-API-KEY`:

```bash
X-API-KEY: <api-key>
```

## Descripción general

El endpoint Crear disputa te permite crear una nueva disputa para un **Asset** (activo digital: URL, dirección, perfil, app, etc.) que fue reportado o bloqueado. Es útil cuando crees que un asset fue marcado por error o si quieres impugnar una decisión de bloqueo.

## Parámetros de la solicitud

| Parámetro     | Tipo   | Obligatorio | Descripción                                                                                                                        |
| ------------- | ------ | ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `content`     | string | Sí          | La URL o el identificador de contenido que quieres disputar                                                                        |
| `email`       | string | No\*        | Correo electrónico de contacto para la disputa. _Obligatorio si la clave de API no está asociada a un usuario que tenga un correo_ |
| `description` | string | No          | Detalles adicionales o explicación de la disputa                                                                                   |

## Respuesta

```json
{
  "id": "12345",
  "content": "https://example-phishing-site.com"
}
```

## Parámetros de la respuesta

| Parámetro | Tipo   | Descripción                                             |
| --------- | ------ | ------------------------------------------------------- |
| `id`      | string | El identificador único de la disputa creada             |
| `content` | string | El contenido (URL) que se disputó                       |
| `message` | string | Mensaje opcional que proporciona información adicional  |

## Errores

| Código de estado | Código de error | Descripción                                                                                                 |
| ---------------- | --------------- | ----------------------------------------------------------------------------------------------------------- |
| 400              | BAD_REQUEST     | Parámetros de entrada no válidos, o ya existe una disputa para este asset con el correo electrónico indicado |
| 401              | UNAUTHORIZED    | Falta la clave de API o no es válida                                                                        |
| 404              | NOT_FOUND       | El asset especificado no existe                                                                             |

## Notas

- Solo se puede crear una disputa por dirección de correo electrónico para un asset específico
- Si el asset solo está bloqueado en EthPhishingDetect pero no en ChainPatrol, se agregará automáticamente una nota a la disputa
- Todas las disputas creadas mediante la API tendrán una nota del sistema que indica que se crearon mediante la API
