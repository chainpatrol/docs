---
title: allow()
description: Agrega una URL o un dominio a la allowlist local de ThreatDetector para que las verificaciones posteriores con url() devuelvan el estado ALLOWED sin llamar a la API de ChainPatrol.
---

<Warning>

Te recomendamos usar este método solo en modo `local` para cargar nuevas entradas
en la **allowlist** (lista de permitidos). En modo `cloud`, la allowlist se completa automáticamente.

</Warning>

## Ejemplo

<CodeGroup>

```js Code
await detector.allow("google.com");

console.log(await detector.url("https://google.com"));
```

```js Output
{
    ok: true,
    url: "google.com",
    status: "ALLOWED"
}
```

</CodeGroup>

## Parámetros

<ParamField body="url" type="string" required>

    La URL que se va a permitir. Puede ser una URL completa o un dominio.

    P. ej., `https://google.com` o `google.com`

</ParamField>

## Valor de retorno

El valor de retorno es una promesa que se resuelve con un objeto de resultado.

### Éxito

Si la URL se agregó correctamente, el objeto contendrá las siguientes propiedades:

<ParamField body="result" type="object" required>
  <Expandable title="propiedades" defaultOpen>

    <ParamField body="ok" type="true" required>
      Esta propiedad será `true` si la URL se agregó correctamente.
    </ParamField>

    <ParamField body="url" type="string">
      La propiedad `url` es la URL que se agregó.
    </ParamField>

  </Expandable>
</ParamField>

### Error

En cambio, si la URL no se pudo agregar, el objeto contendrá lo siguiente:

<ParamField body="result" type="object" required>
  <Expandable title="propiedades" defaultOpen>

    <ParamField body="ok" type="false" required>
        Esta propiedad será `false` si la URL no se pudo agregar.
    </ParamField>

    <ParamField body="url" type="string">
      La propiedad `url` es la URL que intentamos agregar.
    </ParamField>

    <ParamField body="error" type="string">
      La propiedad `error` contendrá un mensaje de error legible para las personas.
    </ParamField>

  </Expandable>
</ParamField>
