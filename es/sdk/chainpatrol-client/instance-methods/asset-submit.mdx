---
title: "asset.submit"
description: "Envía en bloque hasta 100 dominios, URL, perfiles sociales o direcciones de blockchain a ChainPatrol para su clasificación automática de amenazas y su asignación."
---

El método `asset.submit` te permite enviar en bloque **assets** (activos digitales: dominios, URL, perfiles sociales, direcciones de blockchain) a ChainPatrol para su clasificación automática de amenazas y su asignación a las organizaciones correspondientes.

## Referencia de la API

### Firma del método

```typescript
client.asset.submit(request: AssetSubmitInput): Promise<AssetSubmitOutput>
```

### Parámetros

<ParamField path="request" type="AssetSubmitInput" required>
  El objeto de solicitud de envío, que contiene los assets y, opcionalmente, la organización a la que se dirigen.

  <Expandable title="Propiedades de AssetSubmitInput">
    <ParamField path="assets" type="string[]" required>
      Arreglo de cadenas de assets para enviar (máximo 100 por solicitud). Admite dominios, URL, direcciones de blockchain y perfiles de redes sociales.
    </ParamField>
    
    <ParamField path="organizationSlug" type="string">
      Slug opcional de la organización para una clasificación dirigida. Cuando se indica, los assets se clasifican específicamente para esa organización y pueden recibir un escaneo inmediato.
    </ParamField>
  </Expandable>
</ParamField>

### Valor devuelto

<ResponseField name="submittedAssets" type="array" required>
  Arreglo con los detalles de los assets enviados, con los ID de ChainPatrol y la información del escaneo.

  <Expandable title="Objeto de asset enviado">
    <ResponseField name="asset" type="string">
      El contenido original del asset que se envió
    </ResponseField>
    
    <ResponseField name="assetId" type="number">
      ID interno de ChainPatrol para el asset (se usa para el seguimiento y para referencias futuras)
    </ResponseField>
    
    <ResponseField name="scanId" type="number">
      ID del escaneo de seguridad (solo está presente si el escaneo se creó de inmediato, algo más habitual cuando se indica organizationSlug)
    </ResponseField>
  </Expandable>
</ResponseField>

### Comportamiento según la organización

<Tabs>
  <Tab title="Con slug de la organización">
    Cuando se indica `organizationSlug`:

    - ✅ Los assets se clasifican específicamente para esa organización
    - ✅ Se activa el flujo de escaneo inmediato
    - ✅ Es más probable que se devuelva `scanId`
    - ✅ Los resultados se optimizan para el perfil de amenazas de la organización
    - ✅ Procesamiento más rápido y atención prioritaria
  </Tab>

  <Tab title="Sin slug de la organización">
    Cuando se omite `organizationSlug`:

    - 📋 Los assets se procesan para la detección general de amenazas
    - 📋 Los assets se procesan en segundo plano
    - 📋 Es posible que `scanId` no esté disponible de inmediato
    - 📋 Los resultados benefician a todos los usuarios de ChainPatrol
    - 📋 Prioridad de procesamiento estándar
  </Tab>
</Tabs>

## Primeros pasos

### Inicio rápido

<CodeGroup>
```typescript Basic Submission
import { ChainPatrolClient } from "@chainpatrol/sdk";

const client = new ChainPatrolClient({
  apiKey: "cp_live_your_api_key_here",
});

const result = await client.asset.submit({
  assets: [
    "suspicious-domain.com",
    "https://fake-site.net",
    "0x1234567890abcdef1234567890abcdef12345678",
  ],
});

console.log(`Submitted ${result.submittedAssets.length} assets`);
```

```typescript Organization-Specific
const result = await client.asset.submit({
  assets: ["phishing-site.com", "scam-token.org"],
  organizationSlug: "your-organization",
});

// Assets will be classified specifically for your organization
result.submittedAssets.forEach((asset) => {
  console.log(`Asset: ${asset.asset} -> ID: ${asset.assetId}`);
  if (asset.scanId) {
    console.log(`Immediate scan created: ${asset.scanId}`);
  }
});
```

### Patrones de uso básicos

```typescript
// Simple threat submission
async function submitThreats(assets: string[]) {
  const result = await client.asset.submit({ assets });

  console.log(`✅ Submitted ${result.submittedAssets.length} assets`);

  const withScans = result.submittedAssets.filter((a) => a.scanId);
  if (withScans.length > 0) {
    console.log(`🔬 ${withScans.length} assets have immediate scans`);
  }

  return result;
}

// Organization-specific submission
async function submitForOrganization(assets: string[], orgSlug: string) {
  return await client.asset.submit({
    assets,
    organizationSlug: orgSlug,
  });
}
```

## Guía de implementación

### Procesamiento masivo de inteligencia de amenazas

```typescript
async function processThreatFeed(threatFeed: string[]) {
  const chunkSize = 100; // API limit
  const results = [];

  for (let i = 0; i < threatFeed.length; i += chunkSize) {
    const chunk = threatFeed.slice(i, i + chunkSize);

    try {
      const result = await client.asset.submit({
        assets: chunk,
        organizationSlug: "security-team",
      });

      results.push(result);
      console.log(`Processed chunk ${Math.floor(i / chunkSize) + 1}`);

      // Rate limiting - wait between requests
      await new Promise((resolve) => setTimeout(resolve, 1000));
    } catch (error) {
      console.error(`Failed to process chunk starting at ${i}:`, error);
    }
  }

  return results;
}
```

### Monitor de seguridad automatizado

```typescript
import { ChainPatrolClient } from "@chainpatrol/sdk";

class SecurityMonitor {
  private client: ChainPatrolClient;

  constructor(apiKey: string) {
    this.client = new ChainPatrolClient({
      apiKey,
      fetchOptions: {
        headers: {
          "User-Agent": "SecurityMonitor/1.0",
        },
      },
    });
  }

  async submitNewThreats(assets: string[], source: string) {
    try {
      const result = await this.client.asset.submit({
        assets,
        organizationSlug: "internal-security",
      });

      // Log successful submission
      console.log(
        `[${source}] Submitted ${result.submittedAssets.length} assets`
      );

      // Track assets with immediate scans
      const withScans = result.submittedAssets.filter((a) => a.scanId);
      if (withScans.length > 0) {
        console.log(`${withScans.length} assets have immediate scans`);
      }

      return result;
    } catch (error) {
      console.error(`[${source}] Failed to submit assets:`, error);
      throw error;
    }
  }
}
```

## Detalles técnicos

### Límites de solicitudes y restricciones

<Warning>
  **Límites importantes**

  - **Máximo de assets por solicitud**: 100
  - **Longitud de la cadena del asset**: 1-1000 caracteres
  - **Espera recomendada**: 500-1000 ms entre solicitudes
  - **Límites diarios**: contacta a soporte para conocer los planes de uso de alto volumen
</Warning>

<Note>
  **Consejos de rendimiento**

  - Agrupa los envíos en lotes para mayor eficiencia
  - Usa el slug de la organización para un procesamiento más rápido
  - Implementa un manejo de errores y reintentos adecuado
  - Supervisa las cuotas de la API y los límites de solicitudes
</Note>

### Manejo de errores

```typescript
import {
  ChainPatrolClientError,
  ChainPatrolClientErrorCodes,
} from "@chainpatrol/sdk";

async function safeAssetSubmit(assets: string[]) {
  try {
    return await client.asset.submit({ assets });
  } catch (error) {
    if (error instanceof ChainPatrolClientError) {
      switch (error.code) {
        case ChainPatrolClientErrorCodes.MISSING_API_KEY:
          console.error("API key is missing or invalid");
          break;
        case ChainPatrolClientErrorCodes.API_ERROR:
          console.error("API error:", error.message);
          break;
      }
    } else {
      console.error("Unexpected error:", error);
    }
    throw error;
  }
}
```
