---
title: PAGE asset type
description: Report specific webpages on hosting platforms like Tumblr, WordPress, or Linktree without normalizing the URL or blocking the entire domain.
---

The `PAGE` asset type is used to report webpages on a domain. Unlike `URL` asset type, the `PAGE` asset type will NOT normalize the URL string before submitting to **Chainpatrol**.

This allows you to report webpages on sites where the scam or malicious content is hosted on a subpath of the domain, rather than the entire domain being malicious.

<Info>
Use the `PAGE` asset type for hosting platforms like *.wordpress.com, where individual pages may be malicious but blocking the entire domain would affect legitimate content. For these platforms, report the specific page URL rather than the domain.
</Info>

When you submit a report, if you submit a URL that matches one of the domains below, a `PAGE` asset will be created instead of a `URL` asset.

#### Available page domains

```
bit.ly
blur.io
goo.gl
link3.to
linktr.ee
opensea.io
t.co
t.me
telegram.me
tinyurl.com
tumblr.com
twitter.com
beacons.ai
wordpress.com
```
