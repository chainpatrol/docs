## Mastodon

ChainPatrol parses profile and post URLs on `fosstodon.org` and `mastodon.social` as `MASTODON` assets instead of `URL` assets for the server domain. Supported URL forms:

- `/@user` and `/@user@server`
- `/@user/<statusId>` for posts
- `/users/<name>` and `/users/<name>/statuses/<statusId>`

ChainPatrol stores a post as the account that published it. Each account becomes one asset, no matter which server you view it from. Accounts hosted on other servers are stored as `mastodon.social/@user@server`.

| URL | Stored asset |
| --- | --- |
| `https://fosstodon.org/@alice` | `fosstodon.org/@alice` |
| `https://fosstodon.org/@alice/112233445566778899` | `fosstodon.org/@alice` |
| `https://fosstodon.org/@nixCraft@mastodon.social` | `mastodon.social/@nixcraft` |
| `https://fosstodon.org/@scammer@infosec.exchange` | `mastodon.social/@scammer@infosec.exchange` |
