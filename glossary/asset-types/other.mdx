Labels below match [`POST /threats/list`](/external-api/threats-list) and [`POST /detection/list`](/external-api/detection-list), except `ARCHIVE_ORG`, which is documented by [`chainpatrol asset types`](/cli/commands/asset#asset-types).

| Type | Description |
| --- | --- |
| `EMAIL` | Email addresses |
| `GITHUB` | GitHub repositories/profiles |
| `IPFS` | IPFS hashes |
| `OPENSEA` | OpenSea collections/profiles |
| `DEBANK` | DeBank profiles |
| `GOOGLE_FORM` | Google Forms |
| `JOTFORM` | JotForm forms |
| `TAWK_TO` | Tawk.to chat widgets |
| `TEACHABLE` | Teachable courses |
| `ARCHIVE_ORG` | Archive.org Wayback snapshot |
