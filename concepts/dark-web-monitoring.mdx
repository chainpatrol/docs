## Overview

**Dark Web Monitoring** lives under **Employee Protection → Dark Web**. For now, it supports searching leaked credentials against each brand's tracked email domains and addresses.

Leaks are shown with sensitive details masked. You can track which ones you have already reviewed.

When leaks increase for a monitored domain, the system sends an alert to your configured Slack channel with a link back to the page.
